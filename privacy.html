Politique de confidentialité

Cette page fait partie de eb-callback, une page de retour d'autorisation utilisée par une application personnelle de suivi budgétaire (outil banques-enable-banking), exploitée par un particulier pour ses propres comptes bancaires. Elle n'est pas un service public.

Données collectées

Aucune. La page est entièrement statique :

  • aucun cookie, aucun traceur, aucune mesure d'audience ;
  • aucun appel réseau vers un tiers ;
  • les paramètres présents dans l'adresse (code, state) sont lus par le navigateur et affichés à l'écran ; ils ne sont jamais transmis ni enregistrés par cette page.

Hébergement

La page est hébergée par GitHub Pages. Comme tout hébergeur, GitHub peut journaliser les adresses IP des visiteurs selon sa propre politique de confidentialité, indépendante de cette application.

Données bancaires

Cette page ne reçoit ni identifiant, ni mot de passe, ni donnée de compte. L'authentification bancaire a lieu exclusivement sur le site de la banque. Le code d'autorisation affiché est à usage unique et ne permet aucun accès sans la clé privée de l'application, détenue localement par l'utilisateur.
